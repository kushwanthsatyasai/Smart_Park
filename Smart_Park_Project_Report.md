# Smart Park: IoT-Based Smart Parking System
## Project Report

### Abstract
The Smart Park project addresses the growing challenge of urban parking management through an innovative IoT-based solution. This system combines hardware components like ESP32-CAM for visual monitoring, servo motors for barrier control, and IR sensors for occupancy detection, integrated with a Flutter-based mobile application and Supabase backend. The solution provides real-time parking space monitoring, automated access control, and a user-friendly mobile interface for parking space reservation and management.

### Problem Definition
Urban parking management faces several critical challenges:
- Inefficient utilization of available parking spaces
- Time wastage in searching for parking spots
- Manual intervention required for parking management
- Lack of real-time parking space availability information
- Security concerns in parking areas
- Difficulty in managing payment systems
